# Fluxos principais do usuário

## Onboarding e multiempresa
1. Usuário cria conta e confirma e-mail.
2. Usuário cadastra até 3 empresas.
3. Usuário escolhe a empresa ativa ao criar orçamentos.

## Cadastro de cliente
1. Usuário acessa módulo de clientes.
2. Informa PF/PJ, dados de contato e endereço.
3. Salva cliente e visualiza histórico de documentos.

## Criação de orçamento
1. Seleciona empresa emissora e cliente.
2. Define datas de emissão e validade.
3. Adiciona itens, descontos e impostos.
4. Salva como rascunho ou envia para o cliente.
5. Sistema gera link público seguro.

## Solicitação pública de orçamento (cliente)
1. Cliente acessa o link público da empresa.
2. Preenche dados: empresa/solicitante, endereço, e-mail, telefone, CPF/CNPJ.
3. Informa itens desejados para orçamento.
4. Sistema cria um **pré-orçamento** com os itens enviados.
5. Usuário revisa e finaliza com valores, condições e termos.

## Revisão do orçamento
1. Cliente solicita revisão pelo link público.
2. Usuário recebe notificação interna.
3. Sistema cria nova versão (ex.: _rev01).
4. Histórico de versões permanece disponível.

## Aceite e conversão em pedido
1. Cliente aceita orçamento no link público.
2. Status do orçamento muda para **Aceito**.
3. Sistema cria automaticamente um pedido.

## Geração de contrato
1. Usuário converte pedido em contrato.
2. Sistema preenche campos dinâmicos.
3. Contrato é exportado em PDF e enviado ao cliente.
